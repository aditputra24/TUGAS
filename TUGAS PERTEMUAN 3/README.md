# Ocean Dream Samudra Ancol — Tugas Pertemuan 3

Website promosi wisata bahari yang dibuat menggunakan HTML dan CSS.

## Struktur folder

```text
PAWB/
└── Tugas Pertemuan 3/
    ├── images/
    │   ├── gambar-01.jpg
    │   └── ...
    ├── index.html
    └── README.md
```

## Cara menjalankan

1. Buka folder `Tugas Pertemuan 3` di Visual Studio Code.
2. Buka `index.html`.
3. Jalankan menggunakan ekstensi Live Server, atau buka `index.html` langsung di browser.

## Publikasi dengan GitHub Pages

1. Buat repository GitHub, misalnya `PAWB`.
2. Upload folder `Tugas Pertemuan 3` beserta seluruh isinya.
3. Di repository, buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)` jika isi folder `Tugas Pertemuan 3` diunggah langsung ke root repository.
6. Jika folder `Tugas Pertemuan 3` tetap berada di dalam repository, GitHub Pages tidak otomatis menjadikannya halaman utama dari root. Untuk cara paling sederhana, unggah isi folder ini (index.html, README.md, images) langsung ke root repository.

## Catatan

Semua gambar yang sebelumnya tertanam di dalam HTML sudah dipisahkan ke folder `images` dan alamat gambarnya diperbarui agar website lebih rapi dan mudah dikelola.
